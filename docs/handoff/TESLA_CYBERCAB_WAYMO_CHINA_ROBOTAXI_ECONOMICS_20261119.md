## Owner 투자 문제
- 중국이 싸고 좋은 자동차를 대량 생산하는데 **약 30만원 라이다 하나만 달면 자율주행이 되는가?** 저가 차량+센서가 테슬라의 미래 Cybercab 수익성을 잠식하는가?
- 차량 가격보다 **운전자 없이 유료로 안전하게 운영하는 전체 차량+AI+규제+서비스 비용**이 투자 성패의 핵심.
- 과거 대화에서 Tesla가 자동차 판매 사업의 제조·데이터·FSD를 기반으로 로보택시 이동서비스/소프트웨어 수익모델로 이동할 가능성을 집중 논의.

## 라이다와 자율주행의 구분
- 라이다는 거리·형상 지각용 센서이며 `L4` 상용 서비스에 필요한 물체 의미 판단/신호 해석/행동 예측/경로결정/안전 중복/원격지원/규제·보험을 제공하는 단일 완제품이 아니다.
- **소비자 ADAS용 저가 라이다 (~200 USD 또는 약 30만 원)**와 다중 센서/안전 인증 로보택시 패키지를 혼동 금지.
- 중국의 규모경제가 위협적인 이유는 저렴한 EV만이 아니라 **차량 + 라이다·카메라·레이더 + 컴퓨팅 + 인공지능 + 소프트웨어 + 공장**의 종합 단위원가를 낮출 수 있기 때문.
- Tesla의 카메라 중심 방식이 비용이 더 낮을 *수* 있으나, 어떤 방식이 더 안전하고 TCO가 저렴한지는 실제 운행 비교 전 확정 금지.
