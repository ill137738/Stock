- 사용자 동의 없이 실제 매매/주문/자금 이동/외부 서비스 활성화 금지. 이 문서 생성은 투자 승인과 다르다.
- 보고서·장부에는 출처와 계산식을 남기고, 채팅 설명은 한국어로 한다.

## 공통 원칙
산업 성장률 ≠ 개별 기업 매출 성장률 ≠ 주당이익 성장률 ≠ 투자수익률. 매출 희석(모회사), 품질 수율, 원가, 판매가, 자본비용, 밸류에이션, 성장의 이미 반영된 정도를 분리한다. 기업 추천 순위는 최종 매수 순위가 아니라 **연구 우선순위**. 같은 주장/수치를 여러 문서에 중복 복사하지 말고 해당 원장에 링크한다.
