## 이전 가설의 폐기·교정 이력
- `SUPERSEDED` 초기 중국 양식 테마 ETF(516670 등)를 '순수 수산'이라고 묘사한 이전 AI 답변 → 양식(축산 포함) 지수/실제 편입분을 재조회해야 함.
- `SUPERSEDED` Benchmark/BHCCF를 현재 거래 가능한 수산 육종 성장주로 추천 → 사업 매각·상장폐지 확인.
- `SUPERSEDED` BioMar는 Schouw를 통해서만 매수 가능 → 2026-05-28 BIOMAR 독립 상장(단 미국 시장 제외).
- `SUPERSEDED` AQB 상장폐지 확정 서술 → 2026-09-30 SEC 공시에 Nasdaq AQB 등록 상태. 다만 핵심 GMO 사업철수·심각한 지속기업 위험은 별개.
- `SUPERSEDED` fairlife '단백질 2배이므로 원유 생산비 2배' → 공식 +50% 단백질, 원가배분/부산물/회수율 확인 필요.
- `HOLD` 'JBTM은 AI 공장 데이터가 경쟁사보다 많아서 독점적 해자' → 회사의 설치 기반/기술 리더십은 확인, 모델 학습 데이터 권리/경제효과 미확인.
- `HOLD` 메탄 영향으로 모든 단백질이 생선으로 대체 → 실제 육계가 가격·탄소 측면 강한 경쟁자; 소/양과 타 단백질의 대체탄력성 검증.
- `HOLD` 저렴한 연어/메기 → FCR은 가식부/필레/콜드체인 소비자가격을 대표하지 않음.
- `HOLD` 절대적인 '가장 효율적 회사' → 육종·사료·방역·가공은 다른 원가 단계, 동일 기준 경제 모델 없이는 비교불가.

- JBTM 대체 신흥국 기업이 발견될 경우 편입 여부: **미정**.
- BRBR 실적 회복 시 재편입 여부: **조건부 검토**.
